# Perché in questo repository NON c'è il file CNAME

`CNAME` dichiara il dominio personalizzato di GitHub Pages.

Il dominio `inglydesign.it` appartiene al repository di produzione
`inglyum/Sito-claude-code-`. Se anche questo repository dichiarasse lo stesso
dominio, GitHub lo vedrebbe rivendicato da due repository: il sito online
verrebbe scollegato dal dominio e resterebbe irraggiungibile.

Questo repository è l'ambiente di sviluppo: si pubblica su un indirizzo
`github.io` oppure su un sottodominio dedicato (es. `test.inglydesign.it`),
MAI sul dominio di produzione.
