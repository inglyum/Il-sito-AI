## Core Patterns

### Event Delegation (the INGLY way)
```javascript
// ALL events go through the central delegation map in main.js
// NEVER use inline handlers like onclick="..."
// NEVER add per-element addEventListener in render functions

const actions = {
  'open-product': el => prod.openProduct(+el.dataset.id),
  'tog-cat':      el => prod.togCat(el.dataset.v),
  // ... more actions
};

document.addEventListener('click', e => {
  const el = e.target.closest('[data-action]');
  if (!el) return;
  const fn = actions[el.dataset.action];
  if (fn) { if (el.tagName === 'A' && el.getAttribute('href') === '#') e.preventDefault(); fn(el, e) }
});
```

### Rendering Pattern
```javascript
// Always render to innerHTML with template literals

  $('shopGrid').innerHTML = products.map(card).join('');
}
```

### Image Helpers (use these, never raw strings)
```javascript
import { imgTag, imgV, srcsetFor, focalOf } from './utils.js';

// Full <img> tag with srcset and focal point
imgTag(product)

// URL with cache buster
imgV('img/1.webp')  // → 'img/1.webp?v=abc123'

// srcset attribute value (only declared variants)
srcsetFor('img/1.webp')  // → 'img/1-400.webp 400w, img/1-800.webp 800w'

// object-position value
focalOf('img/1.webp')  // → 'style="object-position:40% 30%"'
```

### CSS Architecture
```
variables.css   ← custom properties (colors, type scale, spacing)
reset.css       ← normalize, box-sizing, font smoothing
layout.css      ← nav, hero, wrap, grid, footer
components.css  ← reusable: btn, card, chip, badge, drawer, lightbox
pages.css       ← page-specific: #page-shop, #page-product, etc.
animations.css  ← keyframes, reveal, transitions
responsive.css  ← media queries (mobile-first breakpoints)
```

### Reveal Animation Pattern
```javascript
// In observeAll(), this is how elements become visible:
// 1. Element has class="reveal" (starts opacity:0, translateY:20px)
// 2. IntersectionObserver fires when element enters viewport
// 3. Element gets class="reveal in" (opacity:1, translateY:0)
// 4. Staggered delay: --rd CSS variable (70ms * position, max 630ms)
// CRITICAL: Never add a .reveal element outside .page.active or footer
//           or it will never become visible
```

### Dark/Light Mode
```javascript
// Controlled by data-mode attribute on <html>
// Set by main.js bindMode() on user click
// Persisted in localStorage.ingly_mode
// Falls back to prefers-color-scheme if not set
// NEVER use #000 or #fff hardcoded — always use CSS variables

// In CSS:
// Default: dark mode variables in :root
// Light mode: [data-mode="light"] overrides
// Rule: every background-color must use a variable
```

## Critical Rules for Image CSS
```css
/* CORRECT - never touch animation on these: */
img.pimgph { animation: imgfade .35s ease forwards; }  /* product lightbox image */
img.gimg   { animation: imgfade .35s ease forwards; }  /* gallery image */
img.bimg   { animation: imgfade .35s ease forwards; }  /* bento category image */

/* Safety net - never remove: */
img.pimgph { opacity: 1 !important; }

/* WRONG - this makes images permanently invisible: */
img.pimgph { animation: none; }  /* ← DO NOT DO THIS */
```

## Animation Standards
- All transitions: `var(--dur-fast)` (150ms) for micro, `var(--dur)` (300ms) for standard
- All easings: `ease` for enter, `ease-in` for exit
- Never animate layout properties (width, height, top, left) — only transform and opacity
- Respect `prefers-reduced-motion`: no animations if set, but keep opacity transitions < 100ms

## Accessibility Checklist
- [ ] All interactive elements reachable by keyboard (Tab)
- [ ] Buttons have `aria-label` when icon-only
- [ ] Images have `alt` (empty for decorative, descriptive for informational)
- [ ] Color contrast ≥ 4.5:1 for normal text, 3:1 for large text
- [ ] Focus visible on all interactive elements (`:focus-visible` in CSS)
- [ ] Modals trap focus and restore on close
- [ ] Dynamic content regions use `aria-live` where appropriate
- [ ] Language attribute set: `<html lang="it">` or `<html lang="en">`
