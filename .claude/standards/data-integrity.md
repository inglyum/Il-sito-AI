# Data Integrity Standards — INGLY ENTERPRISE

## Source of Truth Hierarchy
```
1. data/*.json          ← ONLY files ever manually edited (via Admin)
2. data/*.js            ← Auto-generated by Admin on publish (never hand-edit)
3. window.INGLY.*       ← Runtime namespace (loaded by data-loader.js)
```

## Product Schema Validation Rules

### Required fields (block publish if missing)
| Field | Type | Constraint |
|-------|------|-----------|
| `id` | number | Unique across all products |
| `n.it` | string | Non-empty |
| `cat` | string | Must exist in categories.json |
| `sub` | number | ≥ 1, ≤ category.sub.length |
| `mat` | string | Must be key in MAT_ART |
| `price` | number | > 0 |

### Optional fields (warn if unexpected format)
| Field | Type | Default |
|-------|------|---------|
| `n.en` | string | Copied from `n.it` if missing |
| `img` | string | `img/<id>.webp` |
| `gallery` | string[] | `[]` |
| `desc.it` | string | `""` |
| `desc.en` | string | Copied from `desc.it` |
| `tag` | string | `""` |
| `coll` | string[] | `[]` |
| `hero` | boolean | `false` |
| `rev` | number | `0` |
| `sku` | string | `""` |
| `hidden` | boolean | `false` |
| `prod` | number | `3` (days) |

### healData() — auto-repair in memory (never remove)
```javascript
// Repairs before rendering — never crashes the site
function healData() {
  (window.INGLY.P || []).forEach(p => {
    // Rule 3: sub=0 → sub=1
    if (!p.sub || p.sub < 1) { p.sub = 1; console.warn('[INGLY] healed sub=0 for product', p.id); }
    
    // Rule 7: unknown material → first known material
    if (!window.INGLY.MAT_ART[p.mat]) {
      const fallback = Object.keys(window.INGLY.MAT_ART)[0];
      console.warn('[INGLY] healed unknown material', p.mat, '→', fallback, 'for product', p.id);
      p.mat = fallback;
    }
    
    // Missing EN translation → copy from IT
    if (!p.n?.en) p.n.en = p.n?.it || '';
    if (p.desc && !p.desc.en) p.desc.en = p.desc.it || '';
  });
}
```

## Image Path Conventions
```
img/<id>.webp               ← product main (REQUIRED if img field set)
img/<id>-g<n>.webp          ← product gallery (n starts at 1)
img/port-<n>.webp           ← portfolio entry (n starts at 1)
img/cat-<id>.webp           ← category cover
img/sponsor-<n>.webp        ← sponsor logo
img/<season>-<cat>.webp     ← theme category artwork
```

## MV Map (image variants) — CRITICAL
```javascript
// MV is built by Admin during image processing
// Format: { "img/1.webp": [400, 800] }
// MEANING: img/1-400.webp and img/1-800.webp exist on GitHub

// srcsetFor() uses MV to build safe srcset declarations:
function srcsetFor(path) {
  const v = (window.INGLY.MV || {})[path];
  if (!Array.isArray(v) || !v.length) return '';
  const base = path.replace('.webp', '');
  return `srcset="${v.map(w => `${base}-${w}.webp ${w}w`).join(', ')}"`;
}

// NEVER declare a srcset variant that isn't in MV
// If MV says [400] only → only declare the 400w srcset
// If MV is empty → no srcset (browser uses src only)
```

## Validation Script (scripts/validate-data.mjs)
Runs on every push via CI. Blocks merge if any check fails.

Checks performed:
1. All product `cat` values → must exist in categories.json IDs
2. All product `sub` values → must be ≥ 1 and ≤ category.sub.length
3. All product `mat` values → must be in MAT_ART (from products.js)
4. No duplicate product IDs
5. No duplicate SKUs (ignoring empty strings)
6. All `rel` product IDs → must point to existing products
7. All `gallery` paths → must start with `img/`
8. All sponsor `link` values → must be valid URLs
9. All portfolio `link` values → must be valid URLs (if present)
10. All theme IDs → must be unique
11. All `img` paths in products → if set, must end with `.webp`

## i18n Completeness
Every key in `texts.json` must have both `it` and `en` values.
`healData()` copies `it` → `en` for products if `en` is missing.
For `texts.json`: CI warns (does not block) if any key lacks `en`.
