## COME FOTOGRAFARE I PRODOTTI (per il sito)

1. **Sfondo**: bianco o legno chiaro
2. **Luce**: naturale indiretta o ring light
3. **Dimensione**: almeno 800×800px, preferibilmente 1200×1200px
4. **Formato**: salva come WEBP con qualità 85%
5. **Nome file**: `img/<ID>.webp` (es. `img/1.webp`)
6. **Varianti**: se hai foto extra, salva come `img/<ID>-g1.webp`, `img/<ID>-g2.webp` ecc.
7. **Caricamento**: Admin → Libreria Media → seleziona il prodotto → carica foto
